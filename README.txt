脳リフレクソ (Brain Reflexo) - 取扱説明書 (ReadMe)

この度は「脳リフレクソ」をご購入・ダウンロードいただき、誠にありがとうございます。
本作品は、心地よい音と光の泡をタップして弾けさせ、考えすぎた頭をサラッとクリアにするための脳疲労リセット空間（Webアプリケーション / PWA）です。

---------------------------------------------------------
■ おすすめの遊び方（第一推奨）
---------------------------------------------------------
購入時にお渡しする **購入者限定URL** をブラウザで開いてください。

・解凍不要ですぐ起動できます
・iPhone / Android / PC 対応
・Safari や Chrome から「ホーム画面に追加」すると、アプリのように使えます

詳しい手順は sales/purchaser-guide.txt（または購入時の案内PDF）をご覧ください。

ホーム画面への追加（例: iPhone Safari）
  共有 →「ホーム画面に追加」

---------------------------------------------------------
■ Zip について（非推奨・オフライン保険）
---------------------------------------------------------
Zip 単体での起動は、特に iPhone では OS 制限によりトラブルが起きやすいため非推奨です。
可能な限り Web版（限定URL）をご利用ください。

やむを得ず Zip を使う場合の内容:

- 00_iPhone_OPEN_Brain_Reflexo.txt : iPhone向け注意
- Brain_Reflexo.html : iPhone / オフライン用・1ファイル完結版
- index.html / style.css / app.js : PC・Android 用
- README.txt : この説明書

※ 開発用ファイル（server.js / pack.js / scripts など）は zip に含みません。

【Zip での iPhone 起動（非推奨）】
1. Zip を解凍
2. Brain_Reflexo.html を長押し → 共有 →「Safariで開く」
3. 「Safariで開く」が出ない場合は、迷わず購入者限定の Web版URL を使ってください

---------------------------------------------------------
■ 音が鳴らないときの対処法
---------------------------------------------------------
1. 消音（マナー）モードの解除（特に iOS）
2. 端末・アプリ内の音量確認（設定 ⚙️）
3. 画面を一度タップしてから再生
4. ページの再読み込み

---------------------------------------------------------

---------------------------------------------------------
HTML5 / CSS3 / Web Audio API に対応した最新のウェブブラウザ
- Safari / Google Chrome / Microsoft Edge / Firefox
