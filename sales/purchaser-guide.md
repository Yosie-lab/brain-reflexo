# 脳リフレクソ — 購入者さま向けご利用案内

ご購入ありがとうございます。  
本作品は **Webアプリ（PWA）** です。Zipの解凍は不要です。案内のURLを開くだけで起動できます。

---

## 1. 起動方法（いちばん簡単）

1. 下の **購入者限定URL** を Safari（iPhone）または Chrome 等で開く  
2. スタート画面で **Play** / **Endless** / **Meditation** を選ぶ  
3. 泡をタップしてあたまをクリアに

### 購入者限定URL

```
【ここに限定URLを貼り付けてください】
例: https://yosie-lab.github.io/brain-reflexo/p/xxxxxxxx/
```

※ 販売者メモ: ローカルで `node scripts/sync-pages.js` 実行後、`.seller-url.local.txt` のURLをここに転記して PDF/TXT 化してください（原稿は `sales/purchaser-guide.*`）。

---

## 2. ホーム画面に追加（アプリのように使う）

### iPhone（Safari）

1. 限定URLを Safari で開く  
2. 画面下（または上）の **共有** ボタンをタップ  
3. **ホーム画面に追加** を選ぶ  
4. 追加後、ホーム画面のアイコンから起動（フルスクリーンに近い表示）

### Android（Chrome）

1. 限定URLを Chrome で開く  
2. メニュー（⋮）→ **アプリをインストール** または **ホーム画面に追加**

---

## 3. 音が鳴らないとき

1. **消音（マナー）スイッチ**をOFFにする（iPhone側面。オレンジが見えない状態）  
2. 端末の音量を上げる  
3. アプリ内 ⚙️ の音量スライダーが 0% でないか確認  
4. 画面を一度タップしてから再生（ブラウザの仕様）  
5. 改善しない場合はページを再読み込み
